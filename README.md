# Sticky Studio

A sampler you play in the browser: import a track, chop it, play the slices on 16 pads,
record a loop, sequence steps, export a WAV. Built tablet-first.

Live: https://gluestickyx.github.io/STICKY-STUDIO-/

```bash
npm install
npm run dev
```

See `CLAUDE.md` for the architecture rules and the build order.
